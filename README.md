# ITGoApp

## 概要

クイズ形式でITの勉強ができるアプリ

## 前提

- VSCode、VScode Remote - Containersが利用できること
- Gitが利用できること
- WSLが利用できこと(Windowsのみ)
- Dockerが利用できること(Windowsのみ)
- Rancher Desktopが利用できること(Macのみ)

## 開発方式について

- コンテナを利用して開発
- Node.js + React(Vite)形式

## 開発までの流れについて

[README.md](/.devcontainer/README.md)を参照すること

## 開発機能一覧

- DB機能の追加
- 連続問題出題方式機能
- 問題をランダムに出す機能
- 難易度分け(レベル1,レベル2...)機能
- PvP機能
- エフェクト機能
- 残機機能
- スコアの確認(最高スコアや日付に紐づけてのスコア)機能
- キャラクターを搭載して、クリアすると成長する機能
- 本番(試験)の予想得点機能
- 問題のジャンル分け機能(ITパスポート、基本情報...)
- ランキング機能
- 問題の解説機能
- ログイン機能
- 問題をAIに作成してもらう機能
- 背景機能
- タイムリミット機能
- デザインなどUI機能
